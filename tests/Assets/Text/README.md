# Multilingual Text Fixtures

`multilingual-corpus.json` is an original Forma test fixture released under the repository MIT
license. It pins the intended Unicode baseline and covers the script, combining-mark, emoji, and
malformed UTF-16 categories required by the dynamic-text plan.

The corpus's Hebrew, Devanagari, Thai, CJK, and emoji cases use compact test-only Noto subsets
generated by `scripts/generate-multilingual-font-subsets.sh`. The generator pins source revisions
and hashes; the corresponding OFL license is stored beside the font assets.

Malformed UTF-16 cases are arrays of decimal UTF-16 code units because JSON cannot portably carry
unpaired surrogates as text. Tests construct strings directly from these values.

`BidiTest.txt.gz` and `BidiCharacterTest.txt.gz` are deterministic gzip copies of the official
Unicode 17.0.0 UAX #9 conformance corpora. Their source URLs and SHA-256 hashes are pinned in
`assets/unicode/manifest.json`; regenerate and verify them with `Forma.UnicodePipeline` rather than
editing the compressed files directly. They are test-only data covered by the Unicode License V3
notice in `THIRD-PARTY-NOTICES.md`.
